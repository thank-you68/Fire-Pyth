# Website - Fire and Smoke Recognition

Educational prototype. **Not a certified alarm or emergency service.** No passwords or secret keys in any file.

## Run locally
1. Open the project folder in VS Code and click **Go Live** (Live Server). Open `http://127.0.0.1:5500`.
2. Do not open the HTML files by double-clicking: the camera is blocked that way. Use `localhost` or an `https://` address.

## Folders
- `index.html` - landing page (intro + how it works). The detector is on `pages/detection.html`. `pages/detection.html`, `pages/history.html`, `pages/about.html`.
- `assets/css` - `style.css` (phone-first base), `detection.css`, `responsive.css`.
- `assets/js` - `model-loader.js` (settings, loads model; load first), `image-processing.js`, `image-upload.js`, `camera.js`, `prediction.js`, `results.js`, `history.js` (saves past results on this device only), `app.js` (load last).
- `assets/images/` - site images (empty for now).
- `model/` - `model.json` + `.bin` weight files **generated by the converter**. Never create or edit them by hand. Copy ALL files, same names.

## Settings that must match the training notebook (model-loader.js)
`CLASS_ORDER`, `INPUT_SIZE`, preprocessing (`x / 127.5 - 1`, RGB), and `THRESHOLD` (chosen on validation data).

## Publish
Upload the contents of this `website` folder to an https host so `index.html` is at the top.
