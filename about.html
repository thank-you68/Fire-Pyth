What this is

An educational prototype. It looks at one still picture and shows Fire, Smoke, Neither or Uncertain. It uses a MobileNetV2 model (transfer learning) that runs in your browser with TensorFlow.js. No picture is sent to a server.

How it works

You take a photo or upload a JPG or PNG. The site checks the picture, resizes it and prepares the numbers the same way as in training. The model gives three scores. If the highest score is below the threshold, the result is Uncertain.

Main features

Image upload, camera capture, AI image analysis, confidence bars, detection history on this device, and a mobile-friendly layout.

Technology stack

HTML, CSS and plain JavaScript with no framework. TensorFlow.js runs a MobileNetV2 transfer-learning model in the browser. Past results are kept in the browser’s localStorage. The model is trained separately in Google Colab.

Limits

Predictions can be wrong. “Neither” only means the model did not classify the picture as fire or smoke. It never means a place is safe. Only still pictures are analyzed. This is not a real fire alarm and does not replace real fire-safety equipment.
